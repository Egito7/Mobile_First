Parte 1 — Mobile First

O que é Mobile First

  • É uma abordagem em que você projeta primeiro para telas pequenas (celulares) e depois vai expandindo para telas maiores (tablet, desktop).
  • Você começa com o essencial (mobile)…
  • …e adiciona melhorias progressivamente com media queries.

Esta própria página é Mobile First! Diminua e aumente a janela do navegador (ou abra no celular) e observe:

  • o selo no topo, que mostra qual layout está ativo;
  • o menu acima: no celular ele rola para o lado, no desktop as opções quebram em linhas;
  • os cartões abaixo: 1 coluna no celular, 2 no tablet e 3 no desktop.

/* 1º) estilo base = CELULAR (sem media query) */
.grade-exemplo { display: grid; grid-template-columns: 1fr; }

/* 2º) melhoria para TABLET */
@media (min-width: 768px) {
  .grade-exemplo { grid-template-columns: 1fr 1fr; }
}

/* 3º) melhoria para DESKTOP */
@media (min-width: 1024px) {
  .grade-exemplo { grid-template-columns: 1fr 1fr 1fr; }
}

Abra o arquivo css/style.css e procure por @media: todas as regras usam min-width, ou seja, só acrescentam coisas quando a tela fica maior.

Desktop First × Mobile First

Desktop First

/* desktop first */
.container {
  width: 1200px;
}

@media (max-width: 768px) {
  .container {
    width: 100%;
  }
}
  • Começa pelo layout grande.
  • Usa max-width: "quando a tela for até 768px, desfaça e conserte".
  • O celular baixa o CSS do desktop e depois precisa sobrescrevê-lo.

Mobile First

/* mobile first */
.container {
  width: 100%;
}

@media (min-width: 768px) {
  .container {
    width: 1200px;
  }
}
  • Começa pelo essencial (celular).
  • Usa min-width: "quando a tela for a partir de 768px, acrescente".
  • CSS mais simples para o celular, que normalmente tem a internet e o processador mais fracos.

Parte 2 — Animações

O que são e para que servem

Animações em CSS permitem alterar propriedades de um elemento ao longo do tempo, criando movimento, transições suaves e interações visuais, sem precisar de JavaScript.

Elas servem para:

Melhorar a UX (feedback visual)
Guiar a atenção do usuário 3 novas mensagens
Tornar a interface mais moderna
Passe o mouse
Microinterações (hover, loading…)

Um pouco de história

  • Anos 90: a internet era lenta, os computadores tinham pouco processamento e os navegadores eram inconsistentes (Netscape × Internet Explorer). Animações exigiriam demais da CPU e travariam o navegador.
  • Antes do CSS3: animava-se com JavaScript (jQuery, setInterval…) ou com o Adobe Flash, hoje obsoleto. Isso travava a página, era difícil de manter e tinha baixa performance e pouca fluidez.
  • CSS3 (por volta de 2010): trouxe animação nativa com transition, transform, @keyframes e animation, interpolando automaticamente os estados intermediários e usando a aceleração da GPU.

Aceleração por GPU

  • O navegador pode entregar certas animações para a placa de vídeo (GPU) em vez de calcular tudo na CPU, o que as deixa mais rápidas e suaves.
  • transform e opacity não exigem recalcular o layout nem redesenhar a página. São aplicadas direto na etapa final da renderização, chamada composição.
  • Já top, left, width ou margin forçam a CPU a recalcular a estrutura da página a cada quadro.

transition

Anima automaticamente a mudança de uma propriedade entre dois estados (ex.: normal → hover), sem você definir etapas intermediárias. Use para mudanças simples: cor, posição, estados…

Com transition, passe o mouse:

Sem transition, passe o mouse:

button {
  background: blue;
  transition: background 0.3s ease;
}

button:hover {
  background: red;
}

Formato: transition: propriedade duração timing-function;. Use all para animar todas as propriedades que mudarem: transition: all 0.5s;

transform

Aplica transformações visuais (mover, girar, escalar, inclinar) sem alterar o layout ao redor. É a forma mais performática de animar movimento, melhor do que usar top ou left.

A ordem importa

Várias transformações são aplicadas da direita para a esquerda, e cada uma muda o "sistema de eixos" da seguinte. Por isso as duas caixas abaixo terminam em lugares diferentes:

A
transform: translateX(100px) rotate(45deg);
/* gira no lugar e depois anda 100px para a direita */
B
transform: rotate(45deg) translateX(100px);
/* anda 100px na direção do eixo já girado (diagonal) */

transition-timing-function

Define como a velocidade se distribui ao longo da animação. Ela não muda o tempo total: todas as bolinhas abaixo levam exatamente 2 segundos.

linear: velocidade constante
ease: suave (padrão)
ease-in: começa lento
ease-out: termina lento
ease-in-out: lento no início e no fim
.box {
  transition: all 0.5s;              /* usa o padrão: ease */
}

.box {
  transition: all 0.5s ease-in-out;  /* escolhendo a timing-function */
}

@keyframes

Define os estados intermediários de uma animação, como uma linha do tempo. Use para animações complexas ou com várias etapas. O transition só sabe ir de A para B, enquanto o @keyframes pode passar por A → B → C → …

pulse
/* adição do keyframe */
.box {
  animation: pulse 1s ease infinite;
}

/* estrutura do keyframe */
@keyframes pulse {
  0%   { transform: scale(1);   }
  50%  { transform: scale(1.2); }
  100% { transform: scale(1);   }
}

Um exemplo com várias etapas (cor, posição e giro):

etapas
@keyframes etapas {
  0%   { transform: translateX(0)     rotate(0);      background: #3b3f8f; }
  25%  { transform: translateX(100px) rotate(90deg);  background: #c0392b; }
  50%  { transform: translateX(200px) rotate(180deg); background: #16a085; }
  75%  { transform: translateX(100px) rotate(270deg); background: #d35400; }
  100% { transform: translateX(0)     rotate(360deg); background: #3b3f8f; }
}

animation

Aplica uma animação criada com @keyframes a um elemento e controla o comportamento dela: duração, repetição, direção e atraso.

Forma abreviada (shorthand)
  • direction: reverse toca a linha do tempo de trás para frente (100% → 0%).
  • alternate vai e volta (0% → 100%, depois 100% → 0%). Só faz diferença se houver mais de uma repetição.
  • delay é o tempo de espera antes de começar. Clique em "Reiniciar" para vê-lo de novo.

Extra: respeitando quem prefere menos movimento

Algumas pessoas sentem tontura com animações e ativam "reduzir movimento" no sistema (no Windows: Configurações → Acessibilidade → Efeitos visuais → Efeitos de animação). O CSS detecta isso com uma media query:

@media (prefers-reduced-motion: reduce) {
  .notificacao,
  .carregando {
    animation-duration: 3s; /* fica bem mais calma */
  }
}
